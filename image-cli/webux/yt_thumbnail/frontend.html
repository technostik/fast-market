🖼️ YT Thumbnail composer

Compose a 1280×720 thumbnail from up to 4 source images (multi-image compose via -R refs), re-apply overlay text in the long_publish style, then iterate with small edits. Pick a working video to reuse the scene / overlay title suggested by Long Publish, write the result next to that video, and push it to YouTube.

🎞️ Working video

Selecting a video loads its thumbnails and prefills the scene prompt + overlay title saved by Long Publish (or suggested here). Compose, edit and overlay then write <video>_thumb_*; with no video selected they keep writing thumbnail_draft_*.

📥 Source images (up to 4)

Optional: reference them in the prompt as “image 0” … “image 3” to keep a subject. With no sources this is plain text-to-image. Cloud engines need each ref < 512px (auto-downscaled).

⚙️ Generation

🎨 Compose

“Suggest scene” needs a working video; it reuses an existing transcript or transcribes the video first.

🔎 Current

Already have a thumbnail (composed before a Long Publish run, or made elsewhere)? Load it here — it is copied next to the video as <video>_thumb_N, becomes “Current”, and can be pushed.

✏️ Small change (iterate on the current image)

0.50
Local engines (flux2, qwen21, qwen21turbo) use img2img with this strength; cloud engines re-send the image as a reference.

🏷️ Overlay text (long_publish style)

Pick an image from disk to apply the overlay title on it, then push the result. Without one, the overlay is applied on the current base.

🚀 Publish

Select a published video with a thumbnail on screen to enable push.
